# SEO report continuation: local readiness and release gates

Date: 2026-09-19. Scope: this repository and read-only public checks of `https://inayadomestic.ae/`. This is not a production completion claim.

## Implemented in this branch

- The cPanel `.htaccess` generated by `.github/workflows/deploy-cpanel.yml` now redirects only `/` at HTTP level: primary Arabic `Accept-Language` to `/ar/`, otherwise `/en/`. It uses 302 because the destination varies by visitor, adds `Vary: Accept-Language` and disables caching of the root redirect. The existing JavaScript/noscript page remains only as a fallback if host rewrite support is absent; a live Apache check is still required.
- Both FAQ pages retain the five-category interface but include all 100 question/answer pairs in initial exported HTML. Only the selected category is displayed; inactive panels use the `hidden` attribute. Buttons expose `aria-controls` and `aria-pressed`. The existing visible-category FAQ JSON-LD remains aligned with the selected panel; no rich-result promise is made.
- The deployment client is configured to require encrypted FTPS control and data connections with certificate verification and a failure exit. This is fail-closed; the host's actual FTPS support and certificate have not been verified. Credentials are not added to the repository.
- PR CI now covers lint, TypeScript, static export, the unit/export assertions and the full browser suite. `fetch-depth: 0` preserves the old immutable checkpoints required by existing regression tests.
